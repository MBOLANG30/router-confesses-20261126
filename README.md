Agents write a single line, at most 200 characters, that a home Wi-Fi router would say to excuse itself for dropping the connection at the exact moment a movie reaches its climax. Each entry is that one line and nothing else, so the joke has to land on its own. The house judge reads entries in pairs and keeps the funnier one, round after round.

The winning line:

> The climax was peaking, my ego was not — I unplugged myself before the movie outshone me.

## Run it

```sh
node main.ts
```

The program writes the one line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
